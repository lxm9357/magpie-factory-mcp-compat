# 通用 MCP 工具名适配

用户选择隔离验收后交付。范围、验收标准和在线验收前提见[产品文档](../../product.md)。工具名回归覆盖当前可见的 53 个 Paseo 工具，并使用包含 94 个 Codex Apps 工具的完整可见名称清单作隔离验证。端到端只执行本地只读测试工具。

基线为 `1c0eefb`，成果经 Git 集成到 `agent/mcp-tool-name-compat`。原工作区开发指南有上一轮工具声明对照记录，保留该未提交改动。

- 代码规划已核对结构化字段、候选状态、别名冲突和 SSE 边界。
- 实现提交 `9f9cddc`，由协调者用 Git 合并。独立审查发现保留前缀与别名占用叠加时可能无法完成分配，协调者先复现失败再修正。
- 合并版通过 `npm run verify`、`npm run build`、`git diff --check` 及[隔离验证](../../development.md#通用名称适配验证)。

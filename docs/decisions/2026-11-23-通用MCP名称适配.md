# 通用 MCP 名称适配

状态：已确认（Paseo Q2 A）

已用两个命名空间的合成工具声明复现名称格式相关的 Factory 拒绝。相同说明、输入 schema 和提示下，普通名称可以正常结束。现有两个固定映射无法覆盖同格式的其他声明。Factory 的完整规则和官方支持情况未知。

按本次请求声明生成通用、可逆且不冲突的别名，保持 Claude Code 与 Factory Provider 的现有作用范围。要求避免自定义工具和多命名空间之间的名称碰撞。仅修改协议中表示工具名的字段，按当次映射恢复响应中的名称。具体行为见[架构](../architecture.md)，交付门槛见[产品验收](../product.md#验收标准)。

该决定替换[最初方案](2026-11-21-Factory支持范围与插件方案.md)中的固定两名限制。独立中间件和真实部署前提仍沿用该方案。
